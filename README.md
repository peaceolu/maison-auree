# Maison Aurée
Frontend-only luxury skincare landing page (React, TypeScript, Tailwind, Framer Motion). Mock data only.

## Run
    npm install
    npm run dev

## Images
Drop photos into `public/images/` using these names (cream placeholders show until then):
- hero/hero.jpg, hero/hero-inset.jpg
- products/<slug>.jpg and products/<slug>-alt.jpg for: renewal-serum, velvet-cream, cleansing-balm, radiance-elixir
- ingredients/hyaluronic.jpg, niacinamide.jpg, peptides.jpg
- lifestyle/intro.jpg, philosophy.jpg, ritual-01.jpg, ritual-02.jpg, ritual-03.jpg
